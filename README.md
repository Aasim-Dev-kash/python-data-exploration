# python-data-exploration

Semester 1 (Active)

Introductory Python scripts and Pandas/Matplotlib notebooks from INT108 coursework.

## Contents

- scripts/01_basics.py: Variables, loops, functions, lists, dictionaries
- scripts/02_file_handling.py: Reading a CSV file with Python
- data/students.csv: Small sample dataset

## Setup

Install the libraries with: pip install -r requirements.txt

## Run

python scripts/01_basics.py

## Tech

Python 3, Pandas, Matplotlib, Jupyter Notebook
